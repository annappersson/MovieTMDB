# Code Hunt 🎬

A movie discovery app built with React and TypeScript using data from TMDB (The Movie Database).
Browse, search and explore movies, genres and actors.

## Live Demo

https://movie-tmdb-mu-seven.vercel.app/

## Tech Stack

React · TypeScript · React Router · React Query · Context API · Vite

## Features

* View now playing, trending and top rated movies
* Browse movies by genre
* Movie detail pages with cast information
* Actor pages with filmography
* Theme switch (light/dark)
* Pagination and persistent state
* Responsive design

## About

This project was built as part of a frontend development course, focusing on API integration, state management and scalable React architecture.

## API

Data provided by TMDB
https://www.themoviedb.org/

## Run locally

```bash
npm install
npm run dev
```
