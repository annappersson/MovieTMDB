# 🎬 Code Hunt

**Discover your next favorite movie.**

Code Hunt is a movie discovery web application built with React and TypeScript, powered by [The Movie Database (TMDB)](https://www.themoviedb.org/). Explore trending movies, discover films by genre, search for movies and learn more about your favorite actors.

The project was developed as part of my Frontend Developer education, with a focus on API integration, state management, routing and building a responsive, user-friendly application.

## 🌐 Live Demo

[**Explore Code Hunt →**](https://movie-tmdb-mu-seven.vercel.app/)

## ✨ Features

- **Movie Discovery** — Explore now playing, trending and top-rated movies.
- **Genre Browsing** — Discover movies organized by genre.
- **Movie Details** — View individual movie pages with cast information.
- **Actor Profiles** — Explore actors and browse their filmographies.
- **Search & Navigation** — Find movies and navigate between different sections of the application.
- **Light & Dark Mode** — Switch between themes for a personalized browsing experience.
- **Pagination** — Browse movie collections across multiple pages.
- **Persistent State** — Retain selected application state between visits or navigation where supported.
- **Responsive Design** — Enjoy the application across desktop, tablet and mobile devices.

## 🛠️ Tech Stack

- **React** — Building reusable UI components.
- **TypeScript** — Type-safe development and improved code maintainability.
- **React Router** — Client-side routing and navigation.
- **TanStack React Query** — Managing server state and API data fetching.
- **Context API** — Sharing application state across components.
- **Vite** — Fast development environment and production builds.
- **TMDB API** — Movie, genre and actor data.

## 🚀 Getting Started

Follow these steps to run Code Hunt locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### API Configuration

Code Hunt uses the TMDB API to retrieve movie and actor information.

To run the application locally, you may need a TMDB API key, depending on how API access is configured in the project.

1. Create an account at [TMDB](https://www.themoviedb.org/).
2. Request an API key through your TMDB account.
3. Configure the key according to the environment variable setup used in the project.

**Note:** Never commit private API keys or other secrets to a public repository.
